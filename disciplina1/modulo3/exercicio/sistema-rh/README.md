# RH System - Candidate and job matching

This project is an initial structure for the proposed exercise, with a folder structure similar to the ecommerce example.

## Structure

- `data/` -> candidate and job data in JSON
- `src/` -> controller, service, view, events, and worker modules
- `index.html` -> application entry point

## How to run

```bash
npm install
npm start
```

Then open http://localhost:3000.
